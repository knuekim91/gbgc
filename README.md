# 🏫 경북여상 업무 허브

부서별 공유시트·구글폼·업무 링크를 한 곳에서 찾고 등록하는 웹앱입니다.
기존 Notion 페이지 「경북여상 공유시트 모음」을 대체합니다.

**사이트:** https://knuekim91.github.io/gbgc/

---

## 어떻게 동작하나요

```
선생님 브라우저  ──►  GitHub Pages (화면)
                          │
                          ▼
                   Apps Script 웹앱  ──►  구글시트 (데이터)
                   (로그인·권한 확인)      비공개
```

- **GitHub에는 화면 코드만** 올라갑니다. 링크 목록과 계정 정보는 GitHub에 없습니다.
- **링크·계정은 선생님의 비공개 구글시트**에 저장됩니다.
- 로그인 검증, 비밀번호 해시, 부서 권한 확인은 전부 **구글 서버(Apps Script)** 에서 처리합니다.

## 주요 기능

| | |
|---|---|
| 🔍 **통합 검색** | 부서·제목·메모를 한 번에 검색 (`/` 키로 바로 이동) |
| ⭐ **즐겨찾기** | 자주 쓰는 시트를 내 기기에 저장 |
| ⏰ **마감 임박** | 마감일이 2주 이내인 항목만 모아보기, D-day 자동 표시 |
| 🔐 **부서별 권한** | 이름=아이디, 초기 비밀번호 `2026`. 본인 부서만 수정 가능 |
| 📱 **웹앱 설치** | 휴대폰 홈 화면에 추가하면 앱처럼 실행 (PWA) |
| 🌗 **다크 모드** | 시스템 설정을 따르거나 직접 전환 |
| 🔗 **자동 판별** | 주소만 붙여넣으면 시트·폼·문서·노션을 알아서 구분 |

## 권한 구조

| 역할 | 할 수 있는 일 |
|---|---|
| **로그인 안 함** | 링크 보기·열기·즐겨찾기 (`requireLogin=Y` 로 두면 보기도 차단) |
| **부서 담당** | 자기 부서 링크 추가·수정·삭제, 본인 비밀번호 변경 |
| **관리자** | 모든 부서 편집, 사용자 추가·삭제, 비밀번호 초기화, 사이트 설정 |

## 설치

처음 한 번만 설정하면 됩니다. → **[apps-script/설치안내.md](apps-script/설치안내.md)**

요약하면 이렇습니다.

1. 새 구글시트 만들기
2. `apps-script/Code.gs` + `apps-script/Setup.gs` 를 Apps Script에 붙여넣기
3. 메뉴 `[경북여상 허브] → 초기 설치` (Notion 링크 약 50건 자동 이전)
4. `배포 → 웹 앱` 으로 배포하고 주소 복사
5. `config.js` 의 `apiUrl` 에 그 주소 붙여넣기

## 폴더 구성

```
index.html                  화면
config.js                   Apps Script 주소 (여기만 고치면 됨)
assets/app.css              스타일
assets/app.js               동작
manifest.webmanifest, sw.js 웹앱(PWA) 설정
apps-script/Code.gs         백엔드 API
apps-script/Setup.gs        초기 설치 + Notion 링크 이전 데이터
apps-script/설치안내.md      설치 방법
```

## 알아 두실 점

- 이 저장소는 **공개(public)** 입니다. GitHub 무료 계정은 공개 저장소만
  GitHub Pages 배포가 가능하기 때문입니다. 코드만 공개되고 **링크·계정 정보는 공개되지 않습니다.**
- 사이트 주소 자체는 아는 사람이면 누구나 열 수 있습니다.
  개인정보가 담긴 시트가 많다면 `config` 시트에 `requireLogin` = `Y` 를 넣어
  로그인해야 목록이 보이도록 잠가 두시길 권합니다.
- 이 웹앱은 **링크를 관리**할 뿐, 구글시트 자체의 접근 권한은 바꾸지 않습니다.
  시트 공유 설정은 기존처럼 각 시트에서 관리해 주세요.
