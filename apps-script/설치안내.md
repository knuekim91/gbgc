# 설치 안내 (한 번만 하면 됩니다)

전체 15분 정도 걸립니다. 순서대로 따라 하세요.

---

## 1단계 — 구글시트 만들기

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만듭니다.
2. 이름을 **`경북여상 업무허브 DB`** 로 바꿉니다.
3. **이 시트는 공유하지 마세요.** 선생님 본인만 가지고 계시면 됩니다.
   (웹앱이 시트를 대신 읽고 써 주기 때문에, 다른 선생님은 시트 접근 권한이 없어도 됩니다.)

---

## 2단계 — 스크립트 붙여넣기

1. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 클릭합니다.
2. 기본으로 열려 있는 `Code.gs` 의 내용을 모두 지우고,
   이 폴더의 **`Code.gs`** 내용을 통째로 붙여넣습니다.
3. 왼쪽 파일 목록의 **＋ → 스크립트** 를 눌러 파일을 하나 더 만들고 이름을 `Setup` 으로 합니다.
   여기에 이 폴더의 **`Setup.gs`** 내용을 붙여넣습니다.
4. 💾 저장합니다.
5. 스프레드시트 탭으로 돌아가 **새로고침(F5)** 합니다.
   상단에 **[경북여상 허브]** 메뉴가 생깁니다.
6. **[경북여상 허브] → [1. 초기 설치]** 를 실행합니다.
   - 처음 실행할 때 구글이 권한을 묻습니다.
     `고급` → `경북여상 업무허브 DB(안전하지 않음)로 이동` → `허용` 을 눌러 주세요.
     (본인이 만든 스크립트라 나오는 안내입니다.)
   - `links` / `users` / `config` 시트가 만들어지고, Notion에 있던 링크 약 50건이 자동으로 들어옵니다.
7. **[경북여상 허브] → [2. 관리자 계정 추가]** 를 실행하고 선생님 성함을 입력합니다.
   초기 비밀번호는 **`2026`** 입니다.

---

## 3단계 — 웹앱으로 배포하기

1. Apps Script 화면 오른쪽 위 **배포 → 새 배포** 를 클릭합니다.
2. 왼쪽 톱니바퀴 ⚙ → **웹 앱** 을 선택합니다.
3. 다음과 같이 설정합니다.

   | 항목 | 값 |
   |---|---|
   | 설명 | `v1` (아무거나) |
   | 다음 사용자로 실행 | **나 (본인 계정)** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

   > "모든 사용자"로 두어야 선생님들이 구글 로그인 없이 웹앱을 쓸 수 있습니다.
   > 시트 자체는 여전히 비공개이고, 로그인·부서 권한 확인은 스크립트가 처리합니다.

4. **배포** 를 누르면 이런 주소가 나옵니다.

   ```
   https://script.google.com/macros/s/AKfycb.................../exec
   ```

5. 이 주소를 복사합니다.

---

## 4단계 — 웹앱에 주소 연결하기

저장소 최상단의 **`config.js`** 를 열어 주소를 붙여넣고 저장(커밋)합니다.

```js
window.HUB_CONFIG = {
  apiUrl: 'https://script.google.com/macros/s/AKfycb..../exec'
};
```

GitHub 웹에서 바로 고칠 수 있습니다:
저장소 → `config.js` → 연필 아이콘 ✏️ → 수정 → **Commit changes**

1~2분 뒤 사이트가 다시 배포되고, 링크들이 화면에 나타납니다.

---

## 5단계 — 선생님 계정 만들기

웹앱에 관리자로 로그인 → 오른쪽 위 **이름 버튼** → **사용자 관리** 에서
선생님 이름과 담당 부서를 추가합니다. 초기 비밀번호는 모두 `2026` 입니다.

- 부서를 여러 개 맡은 선생님은 `users` 시트의 `dept` 칸에
  `연구부, 전문교육부` 처럼 **쉼표로 구분**해 적으면 됩니다.
- `↺` 버튼으로 비밀번호를 `2026` 으로 초기화할 수 있습니다.
- 선생님 각자는 로그인 후 **이름 버튼 → 비밀번호 변경** 으로 바꿀 수 있습니다.

---

## 설정 바꾸기 (`config` 시트)

| key | 설명 |
|---|---|
| `siteTitle` | 화면 상단 제목 |
| `year` | 학년도 표시 |
| `notice` | 상단 안내 문구 (비우면 안 보임) |
| `depts` | 부서 목록, 쉼표로 구분 — 표시 순서도 이 순서를 따릅니다 |
| `siteUrl` | 알림 메일에 넣을 사이트 주소 |
| `requireLogin` | `Y` 로 두면 **로그인해야 링크가 보입니다** (권장) |

`requireLogin` 은 처음엔 비어 있습니다. 개인정보가 들어간 시트가 많다면
`Y` 로 바꿔 두시길 권합니다.

## 6단계 — 마감 알림 메일 (선택)

마감 1~2일 전에 담당 선생님께 자동으로 메일을 보낼 수 있습니다.

1. 웹앱 **사용자 관리**에서 각 선생님의 **이메일**을 넣습니다. (비워 두면 안 보냅니다)
2. 스프레드시트 메뉴 **[경북여상 허브] → [마감 알림 미리보기]**
   누구에게 무엇이 가는지 먼저 확인합니다.
3. 괜찮으면 **[마감 알림 자동 발송 켜기]** 를 누릅니다. 매일 오전 7시에 발송됩니다.
4. 끄고 싶으면 **[마감 알림 자동 발송 끄기]**.

> 구글 무료 계정의 하루 메일 발송 한도는 100통입니다. 학교 규모에서는 충분합니다.

## 7단계 — 빠른 등록 버튼 (선택)

웹앱에 로그인 → **이름 버튼 → 빠른 등록 도구** 에 있는 파란 버튼을
브라우저 **즐겨찾기 바로 끌어다 놓으세요.**

구글시트를 보다가 그 버튼을 누르면, 제목과 주소가 채워진 등록창이 바로 열립니다.
선생님들께 안내하실 때 이 방법이 가장 손이 덜 갑니다.

## 자주 겪는 문제

**"데이터를 불러오지 못했습니다"**
→ 3단계에서 "액세스 권한이 있는 사용자"가 **모든 사용자**인지 확인하세요.

**"links 시트가 없습니다"**
→ [경북여상 허브] → [1. 초기 설치] 를 실행하세요.

**코드를 고쳤는데 그대로예요**
→ 위의 "코드를 고친 뒤에는" 항목대로 **새 버전**으로 다시 배포해야 합니다.

**수합 현황에 "시트를 열 수 없습니다" 가 떠요**
→ 그 구글시트가 허브 시트를 만든 계정과 공유되어 있지 않습니다.
   해당 시트를 열어 [공유]에 본인 계정을 넣거나, 링크 권한을 편집자로 열어 주세요.

**수합 현황 숫자가 안 맞아요**
→ 결과는 10분간 캐시됩니다. 또 1행은 머리글로 보고 세지 않습니다.
   빈 줄 사이에 값이 있으면 그 줄도 셉니다.

**"links 시트의 열이 부족합니다" 같은 오류가 나요**
→ 예전 버전으로 설치한 시트입니다. 메뉴 **[경북여상 허브] → [시트 열 최신화]** 를 한 번 실행해 주세요.
